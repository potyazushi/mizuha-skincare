# MIZUHA SKINCARE

保湿美容液ブランドを想定して制作した、ポートフォリオ用ランディングページです。

## Overview

乾燥しがちな肌のうるおい環境に着目した、架空のスキンケアブランド「MIZUHA」のLPです。

清潔感・透明感・成分への信頼感を軸に、商品理解から購入検討まで自然につながる情報設計を行いました。

## Purpose

クラウドワークス等のWeb制作案件へ応募する際に、化粧品・美容系LPの制作実績として提示するために制作しました。

## Target

20〜40代を中心とした、乾燥や季節による肌のゆらぎが気になり、成分と使い心地の両方を重視するユーザーを想定しています。

## Features

- PC / Smartphoneレスポンシブ対応
- 美容液の特徴を伝えるファーストビュー
- 保湿メカニズムと成分訴求
- フリー処方表示
- 使用方法・朝夜のケア提案
- サンプルレビュー
- 商品CTA・モバイル固定CTA
- FAQアコーディオン
- `prefers-reduced-motion`対応

## Technology

- React 19
- TypeScript
- Vinext / Vite
- Tailwind CSS 4
- Lucide Icons
- GitHub Actions
- GitHub Pages
- AI生成によるオリジナル商品写真
